# Credits

Pak-Plaza is a catalog, not an authorship claim. Every pak here was created by the NextUI
and MinUI community. Pak-Plaza only collects them by device and, for some, provides a build
adapted to other hardware (the RG353V). Credit belongs to the people and projects below.

## The platform these paks run on

- **NextUI** — by the **LoveRetro** team and contributors.
  https://github.com/LoveRetro/NextUI · https://nextui.loveretro.games
- **MinUI** — the launcher NextUI is built on, originally by **Shaun Inman**
  (https://github.com/shauninman); NextUI's lineage also runs through
  **ro8inmorgan** (https://github.com/ro8inmorgan/MinUI).
- **The NextUI Pak Store** and its contributors — the on-device app catalog this project
  is modelled after.

## Pak authors

- **Game Manager** — UncleJunVIP · https://github.com/UncleJunVIP/nextui-game-manager
- **NextUI Updater Pak** — LanderN · https://github.com/LanderN/nextui-updater-pak
- **NextUI Theme Manager** — Leviathanium · https://github.com/Leviathanium/NextUI-Theme-Manager
- **Syncthing** — the Syncthing project · https://syncthing.net (packaged for NextUI)
- The remaining paks (Boombrick, ClassicPod, Artwork Scraper, ScrapeGoat, Files, FTP Server,
  HTTP Filebrowser, Aesthetics, Wallpaper Studio, Fontleroy, Overlays, Clock, Battery,
  Game Tracker, Disc Organizer, M3U Manager, Rom Inspector, Cheat Downloader Offline, and
  others) come from the **NextUI Pak Store and its contributors**. Each author is named on
  their catalog card where known; if a card is missing or wrong, open an issue and it will
  be corrected.

## RG353V adaptations

The RG353V-adapted builds are prepared by **retrotiv** as part of the
[AnberNext](https://github.com/retrotiv/AnberNext) project. They remain the original
authors' software — adaptation does not transfer authorship.
